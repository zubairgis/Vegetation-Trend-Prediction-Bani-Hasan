# Vegetation Trend Prediction in Bani Hasan, Saudi Arabia

Reproducible R workflows for vegetation trend prediction using ANN, ANN-PSO, ANN-GWO, Random Forest, and XGBoost models.

## Repository Contents

- ANN, ANN-PSO, and ANN-GWO optimization workflows
- RF and XGBoost bootstrap uncertainty analysis
- Residual diagnostics
- Spatial autocorrelation and LISA analysis
- Integrated model ranking framework

## Software

R version 4.5+
